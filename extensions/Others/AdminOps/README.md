# Admin Operations

Adds a proxy-business **Operations** metrics widget to the admin dashboard (active/
suspended services, open tickets, unpaid invoices, paid invoices 30d, new customers 30d).

Full documentation: [`docs/02b-admin-area.md`](../../../docs/02b-admin-area.md).

**Enable:** Admin → Extensions → AdminOps, then add the one-line widget discovery from
[`docs/CORE-TOUCHPOINTS.md`](../../../docs/CORE-TOUCHPOINTS.md) #3 so the widget shows on
the dashboard. Admin branding (logo/name/favicon) is already settings-driven.
