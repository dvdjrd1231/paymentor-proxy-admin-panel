# Ticket Tools

Fills the two ticket features Paymenter core lacks (spec item 3): **quick replies
(canned responses)** and **staff-only internal notes**. Everything else (departments,
priorities, attachments, service association, permissions, notifications) is already
provided by core.

Full documentation: [`docs/modules/ticket-tools.md`](../../../docs/modules/ticket-tools.md).

**Enable:** Admin → Extensions → TicketTools, then use **Support → Canned Responses**
and **Support → Ticket Notes (internal)**.
